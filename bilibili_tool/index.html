💡 下载使用说明

  1. 直接下载（推荐）：复制视频流地址，使用 yt-dlp 或 IDM 下载（需添加 Referer 头）
  2. yt-dlp 命令示例： yt-dlp --referer "https://www.bilibili.com" "视频流URL"
  3. 代理下载：点击"尝试代理下载"，通过 CORS 代理中转下载（受代理服务器限制，可能失败）
  4. 合并音视频：DASH 格式下视频和音频分离，可用 ffmpeg 合并： ffmpeg -i video.m4s -i audio.m4s -c copy output.mp4

仅供学习交流使用，请遵守B站用户协议及相关法律法规
